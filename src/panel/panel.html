快速开始

  1. 连接代理：在「面板设置 → 代理」填入代理脚本（Hopline-proxy.js）的域名、节点路径（环境变量 PATH）和密钥（环境变量 NODE_KEY），点「连接并同步」，面板会自动生成 UUID 并下发给代理，客户端订阅即可获得一批 Cloudflare 优选节点（优选域名与在线优选 IP 来源）；Clash / Mihomo 与 Sing-box 订阅已内置大陆直连分流规则（大陆应用、微软、苹果直连，国外服务走代理）。
  2. 调优节点：用本地工具（如 CloudflareSpeedTest）在自己的网络下测速，把最优 IP 列表托管成一个地址（纯 IP 行 / CSV），填入「优选配置 → 优选 IP 来源」的自定义优选 API；也可以在「优选配置 → 优选域名」换成自己的优选域名。
  3. 检查来源：在「优选配置 → 优选 IP 来源」开关各在线来源，点「测试」可立即查看该来源实时拉取到的 IP；单次订阅最多下发 500 个节点，保证在免费计划 10ms CPU 限制内稳定生成。

订阅地址

单个节点可用 v2rayN / v2rayNG / Shadowrocket / NekoBox 等从剪贴板或二维码导入。单个节点不会随订阅更新（优选 IP 变化后需重新导入）；链接中含 UUID，请勿外传。

协议开关

          
VLESS 协议（默认开启）

          
XHTTP 协议（需 Mihomo / Xray 内核，Sing-box、Surge 等不支持；须绑定自定义域名并开启gRPC）

        

        

          
TLS 与传输

          
仅 TLS 端口（跳过 80/8080 等明文端口）

          

          
默认开启：只下发 TLS 端口节点。关闭后，每个 443 节点另追加一个 80 明文端口节点（名称带「·80」），来源中自带的 8080 / 2052 等明文端口也原样下发。明文节点不加密 UUID 与 Host，更容易被识别封锁；自定义域名还需在 Cloudflare 关闭「始终使用 HTTPS」，否则明文节点无法连接。开启 ECH 时始终只下发 TLS 端口节点。

        

      

      

        
ECH 加密（可选）

        
启用 ECH 加密（需绑定自定义域名）

        

          

          

        

        
开启后，链接类订阅（v2rayN / Shadowrocket 等）的 TLS 节点附带 ech 参数，Clash 订阅附带 ech-opts；Sing-box、Surge、Loon、Quantumult X 订阅不含 ECH。客户端需支持 ECH 才能生效。

      

      

        
保存与生效

        
所有配置修改后点击右下角「保存全部」才会写入 KV 并生效，保存成功后本机房立即生效，其它机房最多约 1 分钟后同步；「重置」将清空 KV 中保存的全部面板配置并还原为初始部署状态。

      

    


    
    

      

        
优选域名

        

          
          
填写后整体替换内置列表（不是追加）。用于「地址来源 → 优选域名」下发的域名节点和 IPv6 解析。只填主机名，不含 http://、端口、路径或通配符，最多 30 个；IP 地址请放到「优选 IP 来源」的自定义优选 API 里。

        

        

          —
          
          
          
        

        
每个域名的运营方都能通过 SNI 看到你的 Worker 主机名，只使用你信任的域名。测试会解析前 25 个域名，看它们是否落在 Cloudflare 段（占用同样数量的子请求，仅管理员手动触发）。IPv6 解析：同时勾选 IPv4 与 IPv6 时只解析前 12 个域名，仅勾选 IPv6 时解析前 25 个；其余仍作为域名节点下发。

        

      

      

        
优选 IP 来源

        
HostMonit 实时优选（按移动 / 联通 / 电信分线路实测，节点名如「移动-01」）

        
uouin 分线路优选（电信 / 联通 / 移动 / 多线 / IPv6，节点名如「电信-U01」）

        
uouin 使用的是对方网站的内部接口（非开放 API），对方可能随时更换签名或封禁，届时该来源静默失效、由其它来源兜底；默认开启，如不需要可关闭。

        
微测网优选（wetest.vip：移动 / 联通 / 电信各 5 个，IPv4 与 IPv6 各一页，节点名如「移动-W01」「移动-W6-01」）

        
微测网读取的是对方的公开页面（HTML 表格，非开放 API），约每 15 分钟更新；版式变化或不可达时该来源静默失效、由其它来源兜底。默认关闭；只拉取当前「IP 类型」筛选需要的页面（IPv4 / IPv6 各占 1 个子请求）。

        
自定义优选 API 1

        

        
自定义优选 API 2

        

        
仅在「仪表盘 → 地址来源 → 优选 IP」开启时生效。所有来源只保留 Cloudflare 段 IP，结果缓存 10 分钟（绑定自定义域名时，同一机房的实例共享缓存），缓存未命中时每个开启的来源占用 1 个子请求。排列顺序：自定义 API 1 / 2 → HostMonit → uouin → 微测网。「测试」会立即重新拉取该来源（不影响订阅缓存，开关关闭时也可测试；自定义 API 使用输入框当前地址，无需先保存）。

这里的设置保存在面板里（和代理的域名、密钥一起），保存时整份下发给代理，代理约 1 分钟内生效（KV 同步与缓存）；之后哪怕代理的 KV 被清空，点「连接并同步」也能原样恢复。有多个代理时，每个代理各有一份设置。

      

      

        
落地与出站

        

        

        
支持 socks5://（可带 user:pass@）、http(s)://，或 host:port（默认按 socks5，端口 1080）；不再支持 Shadowsocks。用户名与密码保存在面板的 KV 里，并随状态下发到代理的 KV。

        

          
        

        
未填写出站代理时，两种出站方式都按直连处理。选「仅走出站代理」并填写了出站代理时，上面的反代 / 落地 IP 不会被使用（它会绕过出站代理）。

      

      

        
备用线路（这个代理）

        
直连不通（例如目标站同在 Cloudflare 上）时，代理会把 TLS 流量交给备用线路按 SNI 转发，并与直连并发竞速。线路是第三方服务器，能看到目标域名与连接元数据；不想经第三方时选「关闭」。非 TLS 流量不会走备用线路。线路表见下方。

        

          
        

        

          
          
          

        

      

      

        
备用线路表（所有代理共用）

        
每行「标签 域名[:端口] [txt]」，# 开头是注释。标签 auto 保留给自动选择；HK / US / SG / JP / KR / DE / SE / NL / FI / GB 是自动选择会用到的地区标签。末尾写 txt = 解析时先查该域名的 TXT 记录（TXT 里放 IP 列表时用），默认只查 A 记录。保存后会立即下发给所有代理。

        

        

          
          
        

      

    


    
    

      

        
代理

        
订阅里的节点指向哪里：可以添加多个代理，订阅会合并所有启用的代理（每个代理各出一套节点，多个时节点名带「·代理名」后缀，总数仍受 500 的上限，平均分给各代理）。点列表里的代理进行编辑。每个代理填写代理脚本（Hopline-proxy.js）所在的域名、它的环境变量 PATH（节点路径）和 NODE_KEY（密钥）。面板用密钥签名后通过 HTTPS 联系代理：UUID 由面板生成并下发给代理（存在代理的 NODE_KV 里），不需要手工填写。密钥只写入、不回显；留空保持不变。

XHTTP 与面板联系代理都要求代理使用自定义域名（Cloudflare 面板 → Workers 与 Pages → 代理 Worker → Domains & Routes 添加）；面板与代理在同一个 Cloudflare 区域（zone）时请把代理设为 Custom Domain。代理需要绑定一个 KV（变量名 NODE_KV）来保存 UUID。「更换 UUID」后旧 UUID 在代理上还会保留 10 分钟，已有客户端更新订阅即可。最多 8 个代理。

      

      

        
基础配置

        
面板与订阅共用此路径（与代理的节点路径互相独立）；修改请到面板 Worker 的环境变量 PATH，修改后订阅地址随之改变，客户端需重新添加订阅。

        

        

        

        
未绑定 KV（绑定变量名 CONFIG_KV）时无法保存面板配置，只有环境变量生效。自定义域名访问面板需先在 Cloudflare 面板 → Workers 与 Pages → 面板 Worker → Domains & Routes 添加。

      

      

        
备份与恢复

        
以 JSON 格式导出全部面板设置（含协议、优选、筛选），可保存到本地或迁移到其他部署；导入后请点右下角「保存全部」生效。备份文件不含代理的密钥与 UUID（它们保存在面板的代理列表里，不在备份范围）；管理密码也不会导出。

        

          
          
          
        

      

      

        
登录会话

        
登录状态保存在浏览器 Cookie 中：使用面板时自动顺延，24 小时未使用即失效；自登录起最长 7 天，到期需重新登录。退出只清除当前浏览器的登录状态；要让所有已签发的登录状态立即失效，请修改管理密码或管理用户名。
